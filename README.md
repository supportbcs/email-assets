# email-assets

Public image assets used in client email signatures and survey emails sent from the BCS Zendesk.
Served via jsDelivr with a fixed commit in the URL, e.g.
`https://cdn.jsdelivr.net/gh/supportbcs/email-assets@<commit>/artin/artin-logo-white-bg.png`.

## artin/
Artin Athletics logo and social icons on a white background, so they stay visible in dark-mode mail apps.
Used in the Zendesk dynamic content "Artin Athletics - Closing" and "CSAT - Artin Athletics - Automation Email Body".
- `artin-logo-white-bg.png`: show at 124 x 29
- `artin-instagram-white-bg.png`, `artin-tiktok-white-bg.png`, `artin-linkedin-white-bg.png`: show at 28 x 28

Do not change a file in place: add a new file or commit, and update the links in Zendesk.
